# 📊 Análise de Dados sobre Diabetes

## 📁 Conjunto de Dados

Este projeto utiliza um conjunto de dados disponibilizado pelo *National Institute of Diabetes and Digestive and Kidney Diseases*.  

Os dados podem ser acessados em:  
https://www.kaggle.com/datasets/akshaydattatraykhare/diabetes-dataset

O objetivo original desse conjunto de dados é prever, de forma diagnóstica, a presença de diabetes em pacientes com base em medidas clínicas e laboratoriais.

### 📌 Características dos dados

- Todos os pacientes são **mulheres**
- Idade mínima de **21 anos**
- Pertencentes à população **Pima Indian**
- O conjunto contém:
  - Variáveis independentes (preditoras): medidas médicas
  - Variável dependente: **Outcome** (presença ou ausência de diabetes)

---

## 🎯 Objetivo do Projeto

O objetivo principal deste projeto é ajustar um **modelo de regressão logística** para:

- Estimar a probabilidade de um paciente ter diabetes  
- Realizar **predições** com base nas variáveis explicativas  
- Avaliar o desempenho do modelo  

---

## 🛠️ Metodologia

O projeto envolve as seguintes etapas:

- Análise exploratória dos dados (EDA)  
- Ajuste do modelo de regressão logística  
- Diagnóstico do modelo  
- Avaliação da qualidade do ajuste e capacidade preditiva  

---
